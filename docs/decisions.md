# Architectural Decisions

## Uso de TypeScript solo en el dominio

**Decisión:** Introducir TypeScript únicamente en la capa de dominio.

**Motivo:**
- Proyecto existente en JavaScript
- Minimizar riesgo
- Maximizar valor arquitectónico

**Consecuencias:**
- Mayor seguridad en contratos
- UI desacoplada
- Posible migración futura a TS
